Project: Multi-Area OSPF Network
Simulation Tool: Cisco Packet Tracer

- End devices: PC0 and PC1
- Routing protocol intended: OSPF
- Simulation platform: Cisco Packet Tracer

IMPORTANT VALIDATION NOTE
The screenshot shows the intended topology and IP labels, but it does not prove the exact OSPF area assignment on every router interface or confirm that end-to-end connectivity succeeds. Verify the configuration in Packet Tracer using commands such as:
- show ip ospf neighbor
- show ip route
- show ip interface brief
- ping <destination-IP>

Before publishing, confirm the OSPF area assignments for the Router1–Router2 and Router2–Router3 links, and ensure the addressing and subnet masks are configured consistently.
