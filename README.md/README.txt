MULTI-AREA OSPF NETWORK

PROJECT OVERVIEW
Designed and simulated a Multi-Area OSPF network using Cisco Packet Tracer to demonstrate dynamic routing, network design, and connectivity verification.

TECHNOLOGIES USED
- Cisco Packet Tracer
- OSPF (Open Shortest Path First)
- IPv4 Addressing and Subnetting
- Cisco IOS CLI

KEY IMPLEMENTATIONS
- Configured OSPF across multiple areas.
- Verified OSPF neighbor relationships and routing tables.
- Tested connectivity between different networks.
- Practiced network troubleshooting.
